# Balkon Çamaşırının Dış Politika Bildirisi

**Resmî ad:** T.C. Balkon Dış İşleri Müdürlüğü — Çamaşır Diplomasisi Protokolü  
**Sürüm:** 1.0-MANDAL  
**Ciddiyet derecesi:** Aşırı / Şaka (aynı anda)

Bu depo, balkona asılmış çamaşırların rüzgâr yönüne göre **bağlayıcı** dış politika bildirisi üretmesini sağlar.  
Çorap artık diplomatik misyondur. Çarşaf anayasadır. Mandal mühürdür.

## Neden bu kadar ciddi?

Çünkü çamaşır kurumadan ülke kurumaz.  
Rüzgâr karar verir. Yazılım sadece tutanak tutar.

## Kurulum

```bash
python3 bildiri.py
```

İsteğe bağlı parametreler:

```bash
python3 bildiri.py --esyalar corap carsaf havlu --yon kuzey --siddet 7 --nem 42
```

## Çıktı örneği

Program çalıştığında şunlara benzer resmi bir nota basar:

- GEÇİCİ NOTA / KESİN İHTAR / MANDAL KARARI
- Rüzgâr yönüne göre diplomatik ton
- Neme göre müzakere süresi
- Tek çorabın daimi temsilciliği
